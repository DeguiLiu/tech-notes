事实依据

USB 输出通道 —— 到 Windows（不经 MIPI）

硬件路径Video SOUT → USB TOP → UVC WRAPE（Header/PTS/EOF）→ EP FIFO → USB PHY
驱动/HALUVC WRAPE HAL 配 WRAPE；UVC WRAPE 驱动 处理中断；端点地址直指 FIFO
通道标识endpoint 0x81/0x82（Bulk IN），无虚拟通道 VC
图像格式UVC：NV12 / YUY2 / Y16 / MJPEG
去向Windows usbvideo.sys 组帧

MIPI 输出通道 —— 到外部 CSI-2 接收端（不经 USB）

硬件路径Video SOUT → Stream SEL → CSI TX Core/Wrapper（VC+DT+WC）→ D-PHY（clock+data lane）
驱动/HALMIPI CSI TX 驱动 校验 lane/VC/DT；MIPI CSI TX HAL 写 Controller/D-PHY
通道标识VC 虚拟通道，由 mipi_vc_mode 设置（NORMAL / SINGLE_VC_PIC / DUAL）
图像格式CSI-2 data type 随 out_fmt：YUV422 / RGB888-YUV444 / Y16 / Y14 / Y10 / Y8
去向外部主控 / FPGA / 桥片
