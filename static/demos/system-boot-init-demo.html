启动不是一跳到 main，而是建立可运行系统的连续交付

固定四层泳道展示调用方向：启动软件/应用为蓝紫色，BSP、driver/HAL 为青色，芯片硬件为橙色；蓝线是调用，绿线是段数据，黄线是调度/事件。

构建配置：主核 + HDR + DDR
控制流Reset_Handler → SystemInit → entry → 实时操作系统 → main
数据流LMA → SRAM/DDR VMA；BSS/UNINIT → zero
调度流main thread ready → scheduler start → components → app
