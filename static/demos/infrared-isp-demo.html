红外图像处理管线：从探测器到显示之间的 ISP

红外热像把探测器的响应值一路加工成可观察、可测温的结果。这条管线从原始 DN 开始，经传感器同步、ISP 校正与增强、像素流 DMA、时序反馈与格式封装，每一段都有明确的配置、计算与搬运边界。每一节配一个四层泳道交互动画。

你将掌握
  1. IRSC 同步如何把探测器原始 DN 变成有节拍的像素流
  2. 双增益校正、HL 融合与增强 / 测温分支
  3. 一级 DMA 三帧缓冲与流消费
  4. 采集时序、丢帧与完成 / 错误事件
  5. 像素格式 data type 与三个尺寸边界

1红外输入：探测器与 IRSC 同步

红外链路的第一步是把探测器的响应值变成有节拍的像素流。探测器输出的原始 DN 是响应值，不是图像；IRSC（红外读出与序列控制）负责把 DN 转成符合后续 ISP 要求的像素节拍。

环节职责产物
业务编排选模式 / 分辨率 / 帧率 / 增益，下发启动预览配置就绪标志
传感器输入选 IRSC source / profile，换算时序、裁剪与门控同步参数
IRSC IP采集时序、有效区、裁剪、丢帧与输出门控像素流
关键区分：启动预览是分阶段编排：参数加载 → 管线 / 流对象就绪 → 才使能输出。命令返回成功只说明配置路径执行完成，不等于已经产生第一帧。
启动预览
  → 参数加载
  → IRSC source / profile 换算
  → 驱动写寄存器
  → 使能输出 → DN 入流

2ISP 处理：校正、增强与测温分支

ISP 管线由静态装配的节点组成，分前段与后段：前段做双增益校正并经 HL 融合，后段做图像增强；测温走独立的 TPD 链，最终在同一份硬件链上形成观察图与测温面阵两套语义。

支路职责产物
双增益前段低 / 高增益校正 → HL 融合融合后像素
图像增强后段SNR / AGC / DDEP / EE / BC / GAMMA / MIRROR观察图
TPD 测温链TPD_CORRECT → TPD_TNR → TPD_SNR → MIRROR_TPD测温面阵
语义边界：DN 是探测器响应值，不等于灰度、RGB 或摄氏温度；Y16 只是 16-bit 单分量容器，不能仅凭格式断言其中已经是温度。

3像素流输出：一级 DMA 与流消费

ISP 后段的结果由 Stream DMA 写入一级三帧缓冲，Video 按用途建模为 PIC / TEMP 流，最终封装到物理接口：UVC 经 USB endpoint 输出，红外 / 测温数据可走 MIPI CSI-2，同一物理链路用 VC 与 data type 区分。

层级职责
一级 DMAS0–S3 按 length + 三帧地址循环写帧
视频流消费缓冲，建模 PIC / TEMP 语义
输出封装UVC payload / CSI-2 packet
坑：length 必须与所在层分辨率、格式、信息行一致，不能照搬最终输出长度；最终 payload 长度不是一级 DMA 长度。
后段结果 → Stream DMA → 三帧缓冲 → 视频流消费
  → PIC / TEMP 语义
  → 封装：UVC endpoint / CSI-2 VC + data type

4时序与同步：节拍与事件反馈

红外链路的节拍由同步控制器约束；DMA 的完成与错误经中断反馈。事件只表达状态，不携带像素，也不自动驱动状态机——帧就绪要靠上层明确的等待、查询或专用流程判断。

事件含义软件动作
WR DONE一帧写完ISR 清标志，映射中断掩码
ERR / FIFO OVERFLOW长度或吞吐异常记录错误状态
帧就绪状态变更回调等待 / 查询 / 专用流程
事实边界：中断 / 回调只表达完成或错误状态；只有状态变更回调有明确触发点，不要补画不存在的错误回调。

5格式与配置：data type 与尺寸边界

像素格式是数据的解释契约：Y16 单分量、NV12 半平面、RGB 三分量。同时有三个尺寸边界必须逐一核对：IRSC 输出、ISP 输入与最终输出，各算各的长度。

边界决定因素
IRSC 输出尺寸时序与裁剪配置
ISP 输入尺寸管线输入分辨率
最终输出尺寸封装类型与接收端解释
注意：分辨率、格式、信息行共同决定每个 DMA 的 length；不能用一个最终长度反推所有层的 length。
length = 分辨率 × 分量数 × 位宽 × 信息行
三个边界分别核对，不能互相反推

一句话总结

红外图像处理链路从探测器原始 DN 出发，经 IRSC 同步、双增益校正与后段增强 / 测温分支，由一级 DMA 三帧缓冲交给视频流消费，再按 data type 与尺寸边界封装输出——配置、计算与搬运每一段都有清晰的分层边界。
